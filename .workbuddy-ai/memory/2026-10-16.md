## 全库代码审查：性能瓶颈与潜在 Bug

- 产出：`CODE_REVIEW-2026-10-16.md`（工作区根目录）。
- 方法：`common/*`(13) + `composables/*`(21) 全量通读，组件抽样 ~30 个；关键函数用
  `typescript.transpileModule` 转译后在 Node 下**实测复现**，不是纯静态推测。
- 已实证的 4 个确定性缺陷：
  1. `isObj` 写成 `toString === '[object Object]' || typeof value === 'object'` → `isObj(null)`
     与 `isObj([])` 均为 true；连带 `deepMerge` **无法覆盖数组**（`{buttons:[1,2,3]}` 被
     `{buttons:[9]}` 合并成 `[9,2,3]`）**且无法置 null**。影响 wd-dialog / wd-toast / wd-notify 全部选项合并。
  2. `debounce({leading:true})` 单次调用触发 **2 次**（trailing 无条件执行）。
  3. `wd-segmented` 选中首项时 `if (left)` 为 0 导致 transform 被省略 → Lynx SetStyle 合并语义
     下旧 `translateX` 残留，滑块不归位。
  4. `wd-tabs` `updateLineStyle()` 只在 immediate watcher 里调（setup 阶段节点未挂载，量到零矩形），
     `onMounted` 未补调 → 首帧指示线失效。
- 重要性能热点：picker-view 拖拽每帧 180+ 次分配；calendar-view 模板内联 `:columns` 每帧新建 144 对象；
  rate 的 touchmove 会在度量不可用时反复发起 getRect；useChildren.sortChildren 每次 link 全树遍历+排序。
- 关键约定（复用）：Lynx `SetStyle` 是**逐属性合并**，「删键不清除已应用的内联属性」——省略某个
  样式属性不会复位，必须显式写值（仓库内 swipe-action 已记录，segmented 因此踩坑）。
- 环境事实：根目录 `node_modules` 为空，依赖只装在 `packages/ui/node_modules`；vitest 需在
  `packages/ui` 下用 `./node_modules/.bin/vitest run`。**全套已跑通**（582s）：284/291 通过，
  7 个失败全在 `test/no-main-thread-script.test.ts`，且**全是 5s 超时而非断言失败** → 无证据
  违反 CONVENTIONS §9，但该守卫测试因「7 个用例各自重读+去注释全库 ~350 文件、无缓存」而失效，
  CI 上会假红。该文件读盘逻辑应缓存到 describe 作用域。
- 追加发现（重要，比单个 bug 更有价值）：**「条件写样式 + SetStyle 合并语义」是一个系统性缺陷模式**。
  Lynx `SET_STYLE` 走 BG `pushOp` → MT `__SetInlineStyles`（`vue-lynx/main-thread/dist/ops-apply.js:124`），
  是逐属性 Object.assign，**省略的键不会清除已应用的内联属性**。仓库已为此付出两次代价并留注释：
  `test/overlay-chain-regression.test.ts:13-18`（wd-transition 的 display:none 永不消失，2026-10-15 真机核实）、
  `wd-swipe-action.vue:51-59`（跟手必须显式写 transition:'none'）。
  同型受害者（本次新发现）：
  - `wd-picker-view.vue:101-107`+`:156`：onTouchStart 置 transitions=false 却不写 transition →
    上次 0.2s 过渡残留 → **首次拖动跟手、之后每次拖动都带缓动不跟手**（表现最直观，优先真机复现）。
  - `wd-toast.vue:63-77`：position 从 top 切 bottom 时 `top:10%` 残留（wd-transition 默认走 v-show
    分支、元素常驻，所以同一实例会累积）。
  - `wd-fab.vue:41-43`：clampToViewport 归零时 transform 被省略 → 旧位移残留。
  - 低危同型：wd-col / wd-text / wd-icon / wd-gap / wd-steps / wd-slider 的条件写样式。
  - 修法：需要「关闭」某样式时显式写中性值，不要省略键。
- 测试覆盖盲区（全绿但仍有缺陷）：P0-1 deepMerge 数组/null、P0-3 segmented 归位、P0-4 tabs 指示线首帧、
  debounce leading 语义，均无用例覆盖；现有 inline-style 回归只断言「样式非空」，抓不到脏值类回归。
