# ADR-010 `vue-lynx` 锁定 0.5.1

- **状态**：已采纳
- **日期**：2026-10-16
- **相关**：根 `package.json` 的 `pnpm.overrides`

## 背景

`vue-lynx` 处于快速迭代期，minor 版本之间出现过渲染行为变化（事件注册表语义、样式下发时机）。组件库有 107 个组件、153 条跨组件依赖，任何运行时行为变化都会放大成全库回归。

## 决策

根 `package.json` 通过 `pnpm.overrides` 锁定：

```jsonc
"vue-lynx": "0.5.1",
"vue": "3.5.43",
"@vue/runtime-core": "3.5.43"
```

**升级必须走 ADR + 回归矩阵全绿**，不允许在功能 PR 中顺手升级。

## 后果

- 上游修复与新特性无法自动获得，需人工评估。
- `peerDependencies` 写 `^0.5.0` 与锁定值存在表述差异（安装时以 overrides 为准），需在升级时同步。

## 推翻条件

- 上游发布稳定版（≥1.0）且提供明确的 breaking change 清单 → 放开为范围锁定（`~1.0.x`）。
- 出现阻塞性 bug 且上游已修 → 按「升级 ADR」流程处理，需跑：事件注册表矩阵、样式回归、真机验收清单。
